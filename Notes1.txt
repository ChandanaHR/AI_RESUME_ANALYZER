         @Table(
          name = "student",

              @UniqueConstraint(columnNames = "email")

b) @Builder annotation: @Builder is a Lombok annotation that helps you create objects in a clean and readable way, especially when a class has many fields.
Without @Builder
Suppose you have:
public class Student {

    private int id;
    private String name;
    private int age;
    private String email;
}
You might have to use a constructor:
Student s = new Student(101, "Asha", 22, "asha@gmail.com");
The problem is that when there are many parameters, it becomes difficult to understand what each value represents.

With @Builder
@Builder
public class Student {
    private int id;
    private String name;
    private int age;
    private String email;
}
Now you can create the object like this:
Student s = Student.builder()
        .id(101)
        .name("Asha")
        .age(22)
        .email("asha@gmail.com")
        .build();
This is called the Builder Pattern.

c) Authresponsedto: AuthResponseDto is typically used to send authentication details back to the frontend after a successful login or registration. Instead of returning the entire User entity (which may contain sensitive data like passwords), the API returns only the required information.
User enters email and password.
AuthController receives the login request.
Spring Security authenticates the user.
A JWT token is generated.
AuthResponseDto is returned to the frontend.
The frontend stores the token and uses it for protected APIs like Resume Upload, AI Analysis, Dashboard, etc.

d) Mapper class: Mapper class is used to convert data from one object to another, most commonly between Entity ↔ DTO (Data Transfer Object). It helps keep your application secure, clean, and maintainable by separating the database model from the API model.
Without a mapper, you would return your User entity directly from the API, which might expose sensitive fields like password.
Instead:
Entity → Represents the database table.
DTO → Represents the data sent to the frontend.
Mapper → Converts between them.
Example
User Entity
@Entity
public class User {

    private Long id;
    private String name;
    private String email;
    private String password;
}
UserDto
public class UserDto {

    private Long id;
    private String name;
    private String email;
}

Notice that password is not included.

UserMapper
@Component
public class UserMapper {

    public UserDto toDto(User user) {
        UserDto dto = new UserDto();
        dto.setId(user.getId());
        dto.setName(user.getName());
        dto.setEmail(user.getEmail());
        return dto;
    }

    public User toEntity(UserDto dto) {
        User user = new User();
        user.setId(dto.getId());
        user.setName(dto.getName());
        user.setEmail(dto.getEmail());
        return user;
    }
}
