======================What is the purpose of generating token in Jwtutil and for what token will be generated?=====================================
The purpose of generating a token in JwtUtil is to allow a user to access protected APIs after successfully logging in, 
without entering their username and password for every request.
---------------For whom is the token generated?
A JWT token is generated for a user who successfully logs in.
Step 1: User registers
Username: chandu, Password: ********
Step 2: User logs in
Spring Boot checks the username and password against the stored user credentials.
Step 3: JWT token is generated
If the credentials are valid, the backend creates a token for that user.
Step 4: User accesses protected APIs
The client sends the token with each protected request. The backend validates it before allowing access.
API	Purpose
POST /register	Create an account
POST /login	Verify credentials and obtain a token
GET /me	Get the logged-in user's profile
Imagine the user logs in successfully.
The backend generates a JWT such as:
eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiJjaGFuZHUifQ.signature
The backend sends it to the frontend. The frontend can then send it when requesting the user's profile:
GET /me
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
The backend validates the token and identifies the user associated with it.

public String generateToken(String email, String role) {
        Date now = new Date();
        Date expiry = new Date(now.getTime() + expirationMs);
        return Jwts.builder()
                .subject(email)
                .claim("role", role)
                .issuedAt(now)
                .expiration(expiry)
                .signWith(key)
                .compact();
    }
